Document control requirements

  • Each SOP must have a title, owner, version number, approval status, effective date and next review date.
  • Only the authorised owner or editor may update a controlled SOP.
  • Review documents at least annually and after major network changes, security incidents, audit findings or relevant legal changes.
  • Mark drafts clearly. Do not label a procedure as approved until the correct manager has approved it.
  • Remove superseded versions from the main directory while retaining them according to the organisation’s record-retention rules.
  • Maintain a change history showing the date, editor, summary of change and approver.
  • Restrict technical runbooks, sensitive network diagrams, configuration backups and credentials to authorised IT staff. Never publish passwords or secret keys on the website.

Website maintenance checklist

  • Check every navigation link after an update.
  • Confirm that mobile layout and keyboard navigation still work.
  • Back up website files and test recovery.
  • Ensure restricted technical information is not published to unauthorised users.
  • Update version and review details whenever a controlled SOP changes.
